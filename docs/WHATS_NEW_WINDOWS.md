# What's New — Windows desktop

## Next batched Thrive release

- Admins can create a pending account invitation from **Server and Admin > Create New Account**. The recipient receives the private setup email, chooses their own password, verifies their email, and completes any authentication required by the server.
- **Pending Accounts** lets an admin resend an invitation or cancel it before it expires. Invitations expire after the server setting (seven days by default); cancellation and expiry release the username.
- **Contacts > Find People** is the searchable server directory. It respects member visibility settings and lets you add a selected person as a contact.
