# What's New — macOS desktop

## Next batched Thrive release

- Admins can send a pending-account invitation from **Server and Admin > Create New Account**. The invited person chooses their own password and completes the server's verification and authentication steps.
- **Pending Accounts** lets admins resend or cancel an invitation before its configured expiry (seven days by default).
- **Contacts > Find People** searches visible members of this server and provides Add to Contacts.
