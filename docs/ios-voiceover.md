# Thrive Messenger on iPhone and iPad: VoiceOver guide

Everything below is also in the app: **Settings > Help and What's New**.

## Chats list (your contacts)

Double-tap a contact to open the chat.

Swipe up or down with one finger on a contact to hear its actions:

| Action | What it does |
| --- | --- |
| Message | Opens the chat |
| Voice message | Opens the chat and starts recording. Activate the button again to stop and send |
| Call | Starts a direct voice call. Only appears when your server offers calling |
| Add to group | Picks one of the rooms you moderate or own, and adds the contact to it |
| Block / Unblock | One action that changes name, so you only ever see the one that applies |
| Remove contact | Takes them off your contact list. Asks you to confirm first |
| Copy username | Copies their username, and says "Copied" |

Touch and hold a contact for the same list without VoiceOver.

Each contact reads as "name, online or offline, status, how many unread".

## Messages in a chat

Each message is one item that reads "sender, time, text, links, reactions, status".

**Double-tap a message to use it:**

- a message with one link opens that link
- a voice message starts playing
- double-tap the same voice message again to pause it, and again to carry on from where it stopped

There is no separate "Play voice message" action. Playing is what activating a voice message does.

Swipe up or down on a message for its other actions: Copy, React, Thumbs up, Open link,
Links in this message, and Edit or Delete for everyone on your own recent messages.

Reactions are thumbs up, thumbs down, heart, laugh, wow, sad, celebrate and check mark, plus any
emoji you type under React, More. There is no "Seen" reaction: Thrive already tells the sender
you have read a message a few seconds after you reach it.

## Hardware keyboard

- **Enter** sends the message you are typing, unless you turn that off in Settings, General, Keyboard.
- **Shift+Enter** or **Option+Enter** always makes a new line.
- **Command+Enter** always sends, even with the Enter setting off.

These only apply with a hardware keyboard connected.

## What you hear

Every action speaks its result: "Copied", "Playing voice message from Dom", "Paused", "Resumed",
"Blocked Dom", "Removed Dom from your contacts", "Ringing". An action that does nothing silently
is a bug — please report it with the exact wording you heard.
