# Changelog

## 0.2.0 - 2026-10-03

- Synchronize passwords for linked Thrive and WordPress accounts over signed HTTPS requests.
- Add replay protection, no-echo handling, and lazy login fallback for older linked accounts.
- Provision WordPress accounts with the Thrive password and a configurable role (Subscriber by default).
- Improve settings labels and help text for screen-reader users.
