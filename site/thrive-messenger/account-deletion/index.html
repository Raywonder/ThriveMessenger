Delete a Thrive Messenger Account

Thrive Messenger accounts belong to the server on which they were created. Deleting an account affects only the currently connected server.

Delete inside the app

  1. Sign in to the Thrive Messenger server containing the account.
  2. Open Settings, then find the Account section.
  3. Choose Delete Account.
  4. Review the server name and deletion warning.
  5. Type the account username and confirm the final destructive action.

What is deleted or unlinked

The server deletes the Thrive account, its authentication credentials and passkeys, contact relationships, access-list memberships, owned rooms, room memberships, eligible messages, and locally stored links to identities such as Mastodon or WordPress. Deleting a Thrive account does not delete an external Mastodon, WordPress, or other provider account.

Before deleting

Account deletion cannot be undone. A self-hosted server may have additional legally required retention rules. Contact that server's operator with questions about its practices.

Need help?

If in-app deletion is unavailable for an account on the default TappedIn service, use Thrive Messenger support. Never send a password, passkey, private key, or complete authentication token.
